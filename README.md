# Beat Marker Pro Web

Browser-only beat marker website.

## Free hosting
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `css/`, and `js/`.
3. Repository Settings → Pages.
4. Deploy from `main` / root.
5. Open the generated Pages URL.

No server or paid hosting is required.

## Features
- Audio upload
- Local browser audio analysis
- Spectral-flux onset detection
- Approximate BPM detection
- 23.976 / 29.97 / 59.94 / exact timing
- Sensitivity
- BPM range
- Offset
- Timeline waveform + beat markers
- CSV / JSON / Premiere marker CSV export

A normal website cannot directly control an open Premiere Pro project. The export files are the bridge for now.
